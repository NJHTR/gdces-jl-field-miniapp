- **做什么**：用 wx.login 拿到的 code 调微信 code2session 换 openid，查员工表，签发 token
- **前端位置**：pages/login/login.js:48 → utils/api.js:46
- **触发时机**：登录页点「微信一键登录」
- **入参**：{ code: string }　**出参**：{ token: string, user: { id, name, role } }
- **报错**：code 无效 / 微信接口失败 / 员工未登记
- **免登录**：是　**现状**：已接入　**优先级**：P0
