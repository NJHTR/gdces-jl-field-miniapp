# 底部导航规格（从 H5 原型 `jl-field/app.js` · `styles.css` 反推）

> 目标：小程序端逐条复刻，不重新设计。

---

## 1. 四种形态，一个胶囊

`dockMode` 只有四个值，胶囊里的内容整体替换：

| 模式 | 胶囊内容 | 由谁进入 |
|---|---|---|
| `default` | 4 个 tab + 滑动镜片 | 初始 / × 关闭 |
| `input` | 相机 + 提示 + 麦克风（可进录音态） | 右钮 💬（仅现场类页面） |
| `expanded` | 胶囊**上方**长出一块面板 | 右钮 ＋ / 上拉 |
| `search` | 圆圈放大镜 + 输入框 | 右上角搜索按钮 |

**胶囊高度全程不变（62px）。** 变的只有里面的内容——这是"变形"而不是"展开"的关键。

---

## 2. 右钮（FAB）是上下文按钮

同一个圆钮，图标和动作随状态变：

| 当前状态 | 图标 | 点一下 |
|---|---|---|
| `default` + 现场/旁站/纠错 | 💬 | 进 `input` |
| `default` + 记录/资料/我的 | ＋ | 进 `expanded` |
| `input` | ↓ | 收起回 `default` |
| `expanded` | × | 收起回 `default` |
| `search` | × | 关闭搜索 |

> **搜索不由 FAB 触发**。搜索只在右上角；FAB 永远是"这一页的主要动作"。

页面到上下文的映射（`DOCK_CTX`）：

```
field / live / correct  → input   （现场类：主线是说话）
inbox / docs / me       → more    （列表类：主线是展开更多）
```

---

## 3. 上拉展开：谁能拖

```js
const canExpand = current === "field" || DOCK_CTX[current] === "more";
```

- ✅ 现场（工作区文件）、记录（视图/筛选）、资料（六宫格）、我的（六宫格）
- ❌ 旁站中、纠错（那是沉浸态，不让拉）

拖的时候**抽屉内容是完整渲染的**，只是外层高度在变——见第 6 节。

---

## 4. 拖动参数（照抄这组数）

| 项 | 值 |
|---|---|
| 抽屉最大高度 `MAX` | **208px** |
| 方向判定阈值 | **8px**（未过阈值不锁定轴向） |
| 越界橡皮筋 | 超过 MAX 后，超出部分 **× 0.22** |
| 拖动中透明度 | `h / (MAX × 0.75)` |
| 松手判定"开" | `h > MAX × 0.55`（≈114px）**或** 速度 `> 0.5 px/ms` |
| 拖动后吞点击 | **320ms** 内忽略 click，防止误触 tab |

**速度参与判定**很重要：快速一甩，即使没拖到一半也会开。这是"有重量"的来源。

---

## 5. 横向拖动换 tab

- 镜片跟手：`translateX(基准 + dx)`
- 横向拉伸：`scaleX(1 + min(0.14, |dx| / 300))` —— 拖得越远，镜片越"被拉长"
- 松手：吸附到**中心距离最近**的 tab（不是"方向最近"）
- 拖动中：`pointer-events: none` 打在 tab 上，防止误触
- **关键坑**：松手时把 `lastLens = 手指位置` 交给下一次渲染，否则新镜片会从旧 tab 重滑一遍（原型真的踩过）

---

## 6. 抽屉的渲染方式（踩过坑，别再犯）

拖动时**不能**把高度设在装内容的盒子上，否则 flex 会把里面的按钮挤到换行（"按日 / 期"这种断字）。

正确结构：

```
.drawer-ghost       ← 只有它改 height，overflow: hidden
  └ .drawer         ← 保持内容自然高度，底对齐，被外层裁掉上半部分
```

视觉上是"面板从下面滑出来"，不是"内容被压扁"。

---

## 7. 动效曲线（全部照抄）

| 元素 | 值 |
|---|---|
| 镜片滑动 | `.46s cubic-bezier(.34, 1.56, .64, 1)`（过冲） |
| 镜片宽度变化 | 同上，属性一起过渡 |
| 抽屉展开 | `drawerGenieIn .44s cubic-bezier(.3, 1.18, .4, 1)`<br>`scale(.38,.1) → 1.04/1.06 → 1`，带 blur |
| 抽屉收起 | `drawerGenieOut .2s cubic-bezier(.55,.06,.68,.19)`<br>`→ translate(16px,48px) scale(.4,.08) + blur(4px)` |
| 输入条 morph | `capsuleIn .24s cubic-bezier(.2,.8,.2,1)`，`scale(.985)` 起 |
| 宫格弹出 | `drawerPop .34s cubic-bezier(.34,1.56,.64,1)` |
| 麦克风按压 | `scale(.86)`，回弹 `.3s cubic-bezier(.34,1.56,.64,1)` |
| 拖动中 | 一律 `transition: none`，松手才交给动画 |
| 底部整体 | 拖动时 `.dock` 下移 **2px**（"被按住"的反馈） |

## 8. 尺寸（px，750rpx=375px 时直接 ×2 转 rpx）

| 元素 | 尺寸 |
|---|---|
| tabbar / 胶囊 | 高 **62**，圆角 **31**，内边距 `0 7`，gap `2` |
| tab | 高 **50**，圆角 **25**，图标高 **22**，字号 **10.5**，gap `2` |
| 镜片 | `top/bottom 6`，宽 = tab 宽，圆角 **25** |
| 角标 | **15×15**，`top 1px`，`left 50% + 9px`，红渐变 |
| FAB | **56×56**，按压 `scale(.94)` |
| 输入条 | 高 **52**，圆角 **26**；mic **42**，cam **40** |
| 宫格抽屉 | 3 列，gap **7**，padding **11**，圆角 **26** |
| 面板抽屉（记录/现场） | 纵向 flex，**不透明 95%** |

## 9. 小程序现状 vs 规格（差距）

| 项 | 原型 | 小程序现状 | 差距 |
|---|---|---|---|
| 模式 | 4 种 | **2 种**（default / search） | ❌ 缺 `input`、`expanded` 是拖动临时态 |
| FAB | 按 ctx 变 | 只有 ＋ / × | ❌ 缺 💬 / ↓ |
| 镜片 | 滑动 + 过冲 + 拉伸 | 静态白底 | ❌ 无 |
| 横拖 | 跟手拉伸、吸附最近中心 | 阈值 40px 切相邻 | ⚠️ 手感差一档 |
| 上拉阈值 | 55% 或速度 | 45%，无速度 | ⚠️ |
| 拖动吞点击 | 320ms | 无 | ❌ |
| dock 下沉 2px | 有 | 无 | ❌ |
| 抽屉收起动画 | genie 缩角 + blur | 高度归零 | ❌ |

## 10. 建议的施工顺序

1. **镜片**（最显眼，纯 CSS + 一个 translateX 状态）
2. **input 模式**（现场页 💬 → 相机/提示/麦克风；FAB 变 ↓）
3. **横拖吸附到最近中心 + 拉伸**
4. **上拉加"速度判定" + 320ms 吞点击 + dock 下沉 2px**
5. **收起 genie**（缩到右下角 + blur）

前两步做完，"像不像"的观感就已经补齐大半。

### 复刻时踩过的坑（记录备查）

1. **`scroll-view` 必须加 `enable-flex`**，否则里面的 flex 布局被忽略，右对齐失效、内容溢出屏幕。
2. **flex 子项的 `min-width:auto` 会压过 `max-width`**，气泡宽度要用 `min-width:0` + 显式宽度。
3. **百分比宽度在 Skyline 里不可靠**，统一用 `750rpx` / `694rpx` 这类显式值。
4. **透明度会相乘**：容器 `opacity` 和水印自身 `opacity` 叠加，会让 8.5% 变成 0.5%。
